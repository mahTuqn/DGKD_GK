## Kết quả scan bảo mật

- Native ZAP 2.17.0 API unauthenticated: 0 High/Medium/Low; 2 informational (`Authentication Request Identified`, `User Agent Fuzzer`); `/api/auth/me` control returned 401.
- Native ZAP 2.17.0 API authenticated: 0 High/Medium, 1 Low-confidence/Low-risk `SEC-OBS-01`, and 2 informational; seeded Admin `/api/admin/summary` control returned 200. Three disposable database fields were returned in JSON and independently checked by `TC-E2E-11` in the UI.
- Native ZAP 2.17.0 built Vite preview: 0 High/Medium/Low; 2 informational (`Information Disclosure - Suspicious Comments`, a low-confidence match on the SVG namespace URL in the minified bundle; `Modern Web Application`).
- `npm run scan:secrets` dùng Gitleaks v8.30.1 đã pin đạt exit 0, quét full Git history (26 commits), không còn finding sau khi `.gitleaksignore` allowlist chính xác hai SHA-256 checksum report bị nhận diện nhầm là generic API key. Exact-head CI 40749428850 cũng pass Gitleaks; không có credential nào được allowlist. Working-tree scan trước đó quét source/config/tài liệu viết tay và 0 finding; evidence ở [production-config evidence](evidence/followup/2026-10-28-production-config-security.json).
- CI đã chạy trên commit `22e5fca` nhưng fail ở quality/API và DAST. Quality thất bại tại assertion doanh thu khi các Vitest files chạy song song trên cùng database; log cũng ghi unique-key conflicts. DAST thất bại vì ZAP không thể ghi report vào bind mount. Fix đã được thêm local: chạy Vitest tuần tự và cấp quyền ghi cho thư mục report riêng; cần run sau để xác nhận.
- Ba native scan trên working tree đã chạy bằng gói ZAP 2.17.0 đã xác minh checksum, PostgreSQL tạm riêng và Vite production preview; reports nằm trong `reports/generated/dast-native/`. Auth site filter dùng hostname-only và requestor xác nhận 200. Active scan ghi thử dữ liệu vào database disposable.
- Local Docker Compose DAST từng bị ngắt do Docker Engine HTTP 500; sau đó GitHub Actions run [40749428850](https://github.com/mahTuqn/DGKD_GK/actions/runs/40749428850) đã pass đủ unauthenticated API, authenticated API và production web preview trên commit `2683e35`. Không có Critical/High/Medium; authenticated API còn một Low-confidence JSON markup observation đã triage. Các scan này không phải đánh giá OWASP toàn diện hoặc kết quả staging/production.
